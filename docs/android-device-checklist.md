# Android 实机验收清单（P1-1）

本清单用于 Android 设备环境验收；在设备上依次执行以下检查。JVM 测试、debug 构建与 lint 结果见 `docs/native-coverage.md`。

```powershell
adb devices -l
.\gradlew.bat :androidApp:assembleDebug
.\gradlew.bat :androidApp:installDebug
.\gradlew.bat :androidApp:lintDebug
# 如后续加入 androidTest：
.\gradlew.bat :androidApp:connectedDebugAndroidTest
```

## 导航

- [ ] 系统返回、左缘返回、三键导航返回只退一层。
- [ ] predictive back 在手势进行中显示正确预览；取消手势后页面不改变。
- [ ] Bottom Navigation 四个 tab 切换后各自保留列表位置和分区；重复点当前 tab 回顶，不新增重复 route。
- [ ] 专题列表 → Reader → 返回：回到原列表位置，不重新请求、不白屏。
- [ ] Reader → 深层楼层页 → 返回：楼层顺序保持，不回到第一楼。
- [ ] Reader 底部“页面操作”可见；推荐/提交优秀/管理动作取消确认后不发出请求，结果页返回仍回到原楼层。
- [ ] 消息导出选择范围后能打开系统文件选择器；清空确认只执行一次，取消不改变列表。
- [ ] 搜索 → 结果 → Reader → 返回：关键词、作者筛选、滚动位置保持。
- [ ] 搜索结果 → 再搜索：旧结果请求取消后不能覆盖新结果。
- [ ] 服务器切换后不显示旧服务器的导航、搜索、草稿或 Cookie。

## 键盘与焦点

- [ ] 首次进入搜索页自动聚焦并弹出键盘；IME Search 触发搜索。
- [ ] 搜索筛选 BottomSheet 打开时不因 IME 抖动；关闭后焦点回到可预期位置。
- [ ] Editor 正文、标题、收件人切换正常；表情 BottomSheet 连续选择后光标仍在正文。
- [ ] Editor 有 IME 时按返回键先收键盘，再按一次才出现“离开编辑”确认。
- [ ] 私信编辑器发送按钮不被键盘遮挡；发送期间返回不会丢弃正在提交的内容。
- [ ] Native 表单/屏蔽名单聚焦、滚动、保存按钮不被 IME 遮挡。
- [ ] 返回键不会在 BottomSheet 打开时直接退出整个页面。

## 滚动与分页

- [ ] Reader 长帖、主题列表、消息、收藏、搜索、Profile 滚动流畅。
- [ ] Reader 作者入口进入的 `show.php` 作者详情按资料卡显示头像、账号字段和“发送短信/用户主题/用户回复”；站点权限提示页降级为只读正文，不出现未知控件。
- [ ] 接近底部自动续页时，已显示 item 不跳动；footer loading 不改变当前位置。
- [ ] 刷新失败保留旧列表；续页失败显示 footer 错误，点击重试只请求失败页。
- [ ] 返回上一页、切换 tab、旋转后滚动位置正确。
- [ ] 进程被系统杀死后重新进入：已加载页按上限重建，scroll anchor 回到原 item；不会自动连续请求几十页。

## 进程死亡与草稿

- [ ] 开发者选项开启“不保留活动”，编辑发帖/回复/私信草稿后切后台，重新进入能恢复标题、正文、收件人、分类。
- [ ] 恢复草稿时明确显示附件数量与“需要重新选择”，不静默丢失。
- [ ] 密码、银行表单、修改密码、购买确认不会被当作草稿恢复。
- [ ] 进程重启后当前 destination、origin、Reader/Topic URL、搜索关键词、消息 tab 正确。
- [ ] 旧于 3 天的分页状态和旧于 7 天的草稿不会被恢复。

## 触摸目标

- [ ] 收藏、回复、更多、消息操作、筛选、tab 的点击区域不小于 48dp。
- [ ] Reader 作者头像/菜单、消息更多菜单、板内筛选在单手操作时可点。
- [ ] 长按/点击不会互相误触。
- [ ] 跨页删除/收藏移动确认对话框列出页数和项目数；部分失败结果的失败项可滚动查看。
- [ ] 奖励与单步战斗有独立确认；确认后不会连续攻击；退出/返回不会重复执行。
- [ ] 奖励子页的物品使用/出售/打开/装备/熔炼、商店购买与光环购买都显示独立确认；熔炼对话框显示站点确认文案，确认后只发送一次，取消不发送请求。
- [ ] 奖励子页刷新后 safeid 变化仍能执行同一目标；目标 id 或页面形状变化时拒绝执行并提示刷新核对。
- [ ] 头像 Photo Picker 选取、预览/取消、上传中按钮禁用、上传后 Profile 核对都可见。
- [ ] 咕咕镇页可查看角色、冷却、装备/背包；动作按钮都逐项确认，没有 WebView、自动连续战斗或自动购买。
- [ ] 背包消耗品显示“打开菜单”而不是装备/丢弃/熔炼；打开菜单不会直接改变状态，选择选项后仍需二次确认，取消不发送请求。
- [ ] 翻牌、礼物、许愿池与宝石工坊中页面实际提供的可信控件显示为动作；只把页面真实提供的控件变成动作，不猜测端点。
- [ ] 争夺等级显示六个属性输入并可滚动；光环天赋预填已勾选 ID；满级提升与改名只在页面提供对应控件时出现，改名输入被站点禁用时不显示动作。
- [ ] 骰子战争显示为单场确认，确认后只发送一次；不会跟随网页端的连续战斗循环。
- [ ] 咕咕镇动作确认后只执行一次并刷新状态；拒绝或不确定显示提示，不自动重试。

## 图片查看器

- [ ] scale ≈ 1 时纵向下滑跟随手指，背景变暗，超过距离/速度阈值关闭。
- [ ] 未超过阈值时 spring 回中心，顶部/底部 controls 恢复原状态。
- [ ] scale > 1 时纵向拖动用于 pan，不触发关闭。
- [ ] 双指缩放过程中不会误触发下滑关闭。
- [ ] 横向拖动优先交给 HorizontalPager，不误关闭。
- [ ] 双击放大、单击显隐、保存原图、系统返回仍正常。

## 操作结果

- [ ] 私信发送后只显示“已发送”当且仅当发件箱出现新对应行；否则显示待核对并提供“检查发件箱”。
- [ ] 跨页批量删除显示“已完成 N 项 / 未完成 N 项”；部分失败可逐项查看。
- [ ] 跨页移动明确显示“目标状态需人工核对”，不伪装成完全成功。
- [ ] 奖励领取/战斗步骤必须二次确认；不会自动连续攻击或自动重试。
- [ ] 评分入口确认后进入站点自己的评分表单；表单只回读同一会话（`safeid`/`ptid` 未变）后提交，会话变化时拒绝提交；提交后显示待核对，不自动重试。已完成评分行不显示动作。
- [ ] 奖励子页操作返回后显示“结果未确认”并提示刷新核对；不会把 HTTP 200 或短回执当作成功，也不会自动重试。
- [ ] 头像上传显示预览、上传中、成功/拒绝/不确定；不确定时不自动重试。
- [ ] 银行日志只读显示时间、类型、对方、金额、币种、附言；不根据余额变化推断交易成功。
- [ ] 咕咕镇页可查看角色、冷却、装备/背包；动作确认后只执行一次，没有 WebView 和自动战斗。
